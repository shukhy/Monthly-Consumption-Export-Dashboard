# 📊 Monthly Export & Consumption Dashboard

An interactive Excel Dashboard built using Power Query, Power Pivot, Data Model, Pivot Tables, and DAX to analyze Stationery & Spare Consumption against Export Performance. The dashboard provides dynamic business insights through KPIs, trend analysis, departmental consumption monitoring, and buyer-wise performance tracking.

## 📈 Key Performance Indicators (KPIs)

| Metric | Description |
| :--- | :--- |
| Total Consumption | Total Stationery + Spare Consumption |
| Total Export Value | Overall Export Value (BDT)|
| Total Export Quantity | Overall Export Quantity |
| Total Stationery Cost | Total Stationery Consumption Cost |
| Total Spare Cost | Total Spare Consumption Cost |
| Stationery % of Export | Stationery Cost as % of Export Value|
| Spare % of Export | Spare Cost as % of Export Value |
| Total Consumption % | Total Consumption as % of Export Value |
| Total Buyers | Number of Active Buyers |
| Total Departments | Number of Departments |

## 🗄️ Data Model
The dashboard uses a relational data model connecting
- Calendar Table
- Export Table
- Department Table
- Buyer Table
- Stationery Consumption Table
- Spare Consumption Table

This structure ensures accurate calculations, efficient reporting, and scalable analysis
